对比参数

Agent 是可调延迟的控制模型，不是真实大模型。两侧使用相同风险检测器，Agent 指令延迟执行，右侧增加即时神经反射仲裁。

危险判断和指令仲裁由 C 核心执行。DEMO MODE 在本机运行同一核心，实时模式在 openvela 中运行。浏览器负责运动、视觉输入转换和碰撞统计。

核心半径 0.34 m，障碍球半径 0.16 m，两侧最大移动速度均为 3.6 m/s。蓄力增加发射速度，连续发射不设数量上限。多个方向同时攻击可能使两侧都无法躲避。

成功率只统计发射时轨迹指向场地中心的球；碰撞记失败，离开场地且未碰撞记成功。在途球不进入分母。结果仅说明当前仿真参数，不能作为实机安全保证。

当前回路仍是 LPLC2、LC4 与 GF 三个聚合节点，未增加虚构神经元。角大小和扩张速度使用演示用几何映射，神经计算参数未改动。

固定仿真步长 25 ms，每步等待 C 核心返回，连接速度只影响演示速度，不作为任何一侧的反应优势。延迟在本次实验中固定，调整后需清空统计。
